# OrbitDesk Product Overview

OrbitDesk is a fictional business workspace used to build dashboards, connect data sources and distribute reports. Each customer account can contain multiple workspaces. Workspace settings, members, dashboards, data connections and export schedules are isolated from other workspaces in the same account.

## Main Objects

- **Workspace:** The security and configuration boundary for members, dashboards, connections and schedules.
- **Dashboard:** A collection of charts built from one or more connected data sources.
- **Connection:** A configured link to an external data source.
- **Export schedule:** A recurring or one-time job that renders a dashboard and sends it to a destination.
- **API credential:** A secret used by an external application to call the OrbitDesk API.

## Support Boundaries

The support assistant may explain product behaviour, provide documented troubleshooting steps and recommend escalation. It cannot make account changes, create credentials, view secret values, issue refunds, contact recipients or guarantee recovery of deleted data.

When an action requires elevated permission or human approval, the response should identify the required role or team rather than claim that the action has been completed.
